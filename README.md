## goals for this software
- a nice looking ui that is easy to use
- the user should be able to add food they bought, or that they have in their kitchen
- the user should also be able to add new recipes
- the user should be able to see what ingredients they are missing from the recipe
- and filter them based on what they have
- user management
- not sure yet if the amounts of ingredients should be taken into account
- possibly add this to render or smth
- at least some level of testing
